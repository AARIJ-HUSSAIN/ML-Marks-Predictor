# ML Marks Predictor API

A machine learning project that predicts student marks based on study hours using Linear Regression and FastAPI.

---

## Features
- Predict marks using ML model
- REST API using FastAPI
- Simple end-to-end AI system

---

## Tech Stack
- Python
- scikit-learn
- FastAPI
- NumPy
